## ✨ Features

- 📚 **7 Learning Units** — Normal Baseline, Inspection, Palpation, Percussion, Auscultation, Disease Patterns, Interventions
- 🎮 **5 Mastery Games** — Pattern Blitz, Decision Tree, Sound ID, Red Flag Simulator, Matrix Challenge
- 📝 **Capstone Exam** — 50-item comprehensive assessment
- 🏆 **Certificate of Mastery** — Printable upon 100% completion
- 📊 **Instructor Dashboard** — Roster, alerts, analytics, reports
- 📋 **Class Record Gradebook** — Auto-computed final grades with Philippine transmutation
- 📱 **Offline-First PWA** — Works without internet after first load
- 📱 **Mobile-Responsive** — Works on phones, tablets, desktops
